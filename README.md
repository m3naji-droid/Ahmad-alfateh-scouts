# موقع فرقة أحمد الفاتح الكشفية

موقع عربي (RTL) بصفحة واحدة `index.html` بلا خادم ولا أدوات بناء:
واجهة عامة، ودخول بأربعة أدوار (كشاف، معلم، ولي أمر، إدارة)، ولوحة إدارة، ونظام نقاط وسلوك، وشارات بعشرة مستويات، وحضور، وتقارير، وتصدير PDF.

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع (Branch: main، المجلد: root).

## الحساب الافتراضي
الإدارة: `admin` / `admin`. غيّر كلمة المرور فور أول دخول.

## ملاحظات مهمة
- كل البيانات تُحفظ في متصفح المستخدم (`localStorage`)، ولا تُشارك بين الأجهزة. استخدم «التقارير والسجل ← نسخة احتياطية» لنقلها.
- الدخول ليس آمناً (كلمات المرور نص عادي في المتصفح). لا تخزّن بيانات حقيقية حساسة قبل ربط الموقع بخادم وتسجيل دخول حقيقي.
- المكتبة الوحيدة الخارجية: SheetJS من cdnjs (لاستيراد إكسل). الخطوط من Google Fonts.
